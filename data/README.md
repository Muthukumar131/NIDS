# Sample Data

This folder contains synthetic traffic and log data created for demonstration and local testing.

- `sample_auth_logs.csv` contains fictional failed and successful login attempts.
- `sample_vpn_logs.csv` contains fictional VPN login, connect, disconnect, and authentication failure events.
- `sample_capture.pcap` is a small synthetic PCAP generated with Scapy for demonstration only.

All data is clearly synthetic and must not be used to represent real network activity.
